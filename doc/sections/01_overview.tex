\section{개요 (Overview)}

\subsection{프로젝트 목적}
\texttt{liboqs-analysis}는 포스트양자암호(PQC) 라이브러리 \texttt{liboqs}의 분석/실험 목적 변형 빌드로 보이며,
현재 코드베이스 기준으로는 KEM(Key Encapsulation Mechanism) 경로에 집중된 구성이다.

핵심 퍼블릭 헤더는 \texttt{include/oqs/oqs.h}, \texttt{include/oqs/kem.h}, \texttt{include/oqs/common.h}이며,
산출물은 \texttt{build/lib/liboqs-algorithms.a}, \texttt{build/lib/liboqs-internal.a} 정적 라이브러리 형태로 확인된다.

\subsection*{Assumption}
본 문서는 사용자 제공 작업 디렉터리(\texttt{build/lib})와 상위 프로젝트 트리 스캔 결과를 기반으로 작성되었다.
상위 원본 저장소(예: upstream liboqs)와의 동기화 상태는 본 문서 범위에 포함하지 않는다.
