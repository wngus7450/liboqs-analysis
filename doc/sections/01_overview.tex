\section{개요 (Overview)}

\subsection{프로젝트 목적}
본 문서는 \texttt{liboqs-analysis}의 KEM(Key Encapsulation Mechanism)과 전자서명(Signature, SIG) 구현 구조,
빌드 산출물, KAT 테스트 흐름을 정리한다.
현재 프로젝트는 KEM/SIG 알고리즘을 공통 API로 선택하고 실행하는 흐름을 중심으로 구성되어 있다.

\subsection{주요 구성}
\begin{itemize}[leftmargin=*]
\item 공개 인터페이스: \texttt{include/oqs/*.h}
\item 통합/공통 헤더: \texttt{include/oqs/oqs.h}, \texttt{include/oqs/common.h}
\item KEM/SIG 헤더: \texttt{include/oqs/kem.h}, \texttt{include/oqs/sig.h}
\item 핵심 구현: \texttt{src/common}, \texttt{src/kem}, \texttt{src/sig}
\item 테스트: \texttt{tests/kat\_kem.c}, \texttt{tests/kat\_sig.c}, \texttt{tests/test\_helpers.*}
\item 빌드 산출물: \texttt{build/lib/liboqs.a}, \texttt{build/lib/liboqs-internal.a}
\end{itemize}
